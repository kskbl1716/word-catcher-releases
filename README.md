# WordCatcher 下载

Windows 雅思词汇学习桌面应用，支持离线词典、词书、卡片复习、听音拼写、学习报告与文章练习。

[下载最新版本](https://github.com/kskbl1716/word-catcher-releases/releases/latest)

- `WordCatcher-Setup-版本.exe`：安装版，安装后可在设置页检查后续更新。
- `WordCatcher-版本-portable.exe`：绿色版，下载后运行；后续更新需手动替换 EXE。
- `latest.yml` 与 `.blockmap` 是安装版更新文件，用户无需手动运行。

v0.15.2 及以前需要先手动安装一次 v0.16.0，之后才能通过软件更新。学习数据格式不变；请先保留原有学习备份。当前文章练习和未完成会话不会跨重启保存。

当前版本未配置发布者代码签名，Windows 可能提示未知发布者。请核对本仓库正式发行附件与 GitHub 显示的 SHA-256 摘要；摘要不等同代码签名。应用内更新需要能访问 GitHub 服务。

AI 练习需用户自行配置自己的服务，生成内容不是雅思真题，需核对。个人设置、API Key 和学习记录不进入本下载仓库。
